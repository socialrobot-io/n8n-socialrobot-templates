# SocialRobot n8n workflow templates

Ready-to-import [n8n](https://n8n.io) workflow templates for the
[SocialRobot community node](https://github.com/socialrobot-io/n8n-nodes-socialrobot).
Each one shows a different social media automation pattern: single-platform
publishing, cross-posting to every network, RSS and Google Sheets content
pipelines, AI caption writing, and AI video/image generation with Seedance and
gpt-image-2.

## Install the node first

In your n8n instance: **Settings -> Community nodes** -> install
`@socialrobot-io/n8n-nodes-socialrobot` (or `npm install @socialrobot-io/n8n-nodes-socialrobot`
if you run a custom image). You need an API key from
[socialrobot.io](https://socialrobot.io) (Scheduler -> API Keys).

Then import any JSON from [`workflows/`](workflows/) via **Workflows -> Import from File**.

## Node types used

One node: `@socialrobot-io/n8n-nodes-socialrobot.socialRobot`.

- Publishing: set **Resource** to one of Instagram, X (Twitter), LinkedIn,
  TikTok, Facebook, Pinterest, Bluesky, Mastodon, or Threads (each a **Create**
  operation).
- Management: **Resource** = Post (get, get many, delete, reschedule) or
  Account (get many).
- Credential: `socialRobotApi`

Multi-platform templates use one SocialRobot node per platform, fanned out from
the source, so each node shows only the fields that platform supports.

## The templates (36)

| Category | Templates |
|---|---|
| Single-platform posts | Post to Instagram (image, video, binary download), X (text, text+image), LinkedIn, TikTok, Facebook, Pinterest, Bluesky, Mastodon, Threads |
| Cross-posting | Every platform at once, microblog set (X/Bluesky/Mastodon/Threads/LinkedIn), visual set (Instagram/Pinterest/Facebook/Threads) |
| Scheduling | Future date, daily post, Google Sheets calendar |
| Content sources | RSS to every platform, RSS to Bluesky+Mastodon, blog to X/LinkedIn/Facebook |
| AI captions | All 9 platforms flagship, Instagram+Pinterest, daily Bluesky/Mastodon, RSS summaries, Sheets calendar, repurposing |
| Draft review | AI writes for all 9 platforms, saves as drafts for human approval |
| AI media | Seedance text-to-video -> TikTok, gpt-image-2 -> Instagram + Pinterest |
| Management | List scheduled/failed posts, get/delete/reschedule post, list accounts |

AI templates use n8n's real LangChain nodes (`lmChatOpenAi`, `agent`,
`outputParserStructured`) wired like n8n's top-ranked templates. The AI media
templates use Replicate (Seedance 2.0) and OpenAI images (`gpt-image-2`) via
HTTP Request with proper polling loops.

Every template ships with annotated sticky notes: who it is for, how it works,
setup steps, and requirements, matching n8n's template guidelines.

## Regenerating

The whole set is generated by Python, not hand-written:

    python3 generate_templates.py     # builds + annotates all workflows
    python3 generate_descriptions.py  # writes submission-descriptions.md

Edit the `templates` list in `generate_templates.py` and rerun. The generator
auto-arranges nodes (trigger left, fan-out columns, AI sub-nodes under their
agent), renames nodes descriptively, adds sticky notes, validates every file as
JSON, and deletes stale outputs. CI runs the same validation on every push.

## Submitting to n8n.io

1. Pick a file from `workflows/` and its description from `submission-descriptions.md`.
2. Log in to n8n.io with GitHub, go to Workflows -> Create -> New workflow template.
3. Upload the JSON, paste the description, category Social Media.

Best search-to-competition ratio right now: Bluesky, Mastodon, Threads, and the
two AI media generation templates (the highest-view pattern in n8n's gallery).
